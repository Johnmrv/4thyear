# Description
This program analyzes student examination scores using arrays and local modules in Node.js. It can add, remove, find, and filter scores. It also calculates the average, highest score, lowest score, passing and failing scores, and sorts the scores from highest to lowest.

The program also includes grade conversion and score frequency for the additional points.

# Local Modules Used
- arrayOperations.js
- statistics.js

# How to Run
1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Type:

   node app.js

4. Press Enter to run the program.
